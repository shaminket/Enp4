Arquitectura para Backend Real (Sin fingir base de datos): Actualmente este Centro de Administración almacena los datos de forma real e instantánea en el localStorage del navegador mediante el módulo DataStore. Para que los cambios realizados por un administrador se reflejen de inmediato en los teléfonos de los más de 50 alumnos del Grupo 415, se requiere:
  • Una base de datos en la nube (ej. Supabase con PostgreSQL o Firebase Firestore).
  • Un servicio de autenticación con contraseña o Google OAuth para que solo el jefe de grupo y administradores autorizados puedan publicar.
  • Una regla de seguridad (Row-Level Security) que permita lectura pública para los alumnos y escritura privada solo para administradores autenticados.
La capa DataStore.syncWithCloud() en js/data.js ya tiene definidos los hooks para conectarse a esa API cuando se configure.
